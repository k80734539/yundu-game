# TEST_CHECKLIST — 手動驗收清單

開發伺服器：`npm run dev`；正式版：`npm run build && npm run preview`。
自動截圖：`npm run build && node tools/shot.mjs <名稱> tools/act/<腳本>.js`（需要 Playwright；console 有錯誤會失敗）。

## 0. 開始
- [ ] 第一次開啟出現標題畫面，輸入名稱 → 「新的冒險」進入晨曦鎮，聊天框有歡迎訊息與 MVP 公告。
- [ ] 重新整理後標題出現「繼續冒險（名稱 職業 Lv）」，按下回到上次的地圖與位置。
- [ ] 畫面上方出現新手教學提示，完成條件後自動換下一步；× 可關閉，導覽員對話可重新打開。

## 1. 核心（階段 1）
- [ ] 點地面：角色沿 A* 路徑走過去，出現黃色菱形標記；繞過樹、房屋、水；不會斜切牆角。
- [ ] 按住滑鼠：角色持續往游標方向走。
- [ ] 走路平順，背景與角色不抖動；相機平滑跟隨。
- [ ] 點怪物：自動走過去並攻擊；傷害數字彈出、打擊瞬間停頓、畫面輕微震動、怪物閃白並後仰。
- [ ] 怪物死亡淡出後消失，幾秒後在別處重生。
- [ ] 攻擊動畫中角色大小不變（只有手臂、武器動）。
- [ ] 走到樹或房子後面時，那個物件變半透明；走出來恢復。
- [ ] 滾輪可以整數倍縮放畫面，像素保持清晰（沒有模糊）。

## 2. 數值（階段 2）
- [ ] Alt+A 能力值：點「+」加點，花費依 RO 公式增加；ATK/HIT/FLEE/ASPD 等跟著變化。
- [ ] 打怪得到經驗，左上 Lv/Job 經驗條與底部經驗條增加；升級時有光柱與「LV UP」、HP/SP 補滿、得到能力點數。
- [ ] 怪物攻擊會 MISS／LUCKY；玩家會爆擊（黃色大字）。

## 3. 世界（階段 3）
- [ ] 晨曦鎮南、東兩個傳送點；走進去淡出 → 新地圖淡入，上方顯示地圖名＋建議等級。
- [ ] 傳送點上方顯示目的地與建議等級（綠＝適合、紅＝太難、灰＝太簡單）。
- [ ] 7 張地圖都能到達：晨曦鎮 → 草原／森林 → 海岸／礦坑 B1 → 沼澤／礦坑 B2，也能走回來。
- [ ] 右上小地圖顯示玩家（閃爍）、傳送點、NPC；方向與畫面一致。
- [ ] M 鍵世界地圖：所有地圖縮圖與連線、目前位置、建議等級、MVP 狀態。
- [ ] 礦坑較暗，玩家周圍與火把附近有光；火把火焰會動。

## 4. 怪物（階段 4）
- [ ] 被動怪（啵啵團、跳跳兔…）不打牠不會攻擊；主動怪（礦坑蝙蝠、骷髏…）靠近就頭上冒「!」追過來。
- [ ] 同時追擊玩家的怪物最多 3 隻（礦坑裡站著等也不會超過 3 隻）。
- [ ] 哥布林被打時附近的哥布林會一起來；跑遠一點怪物會放棄並走回去。
- [ ] 怪物掉落道具彈跳落地，滑鼠移上顯示名稱，點擊撿起（聊天框提示）；60 秒後消失。
- [ ] MVP：森林的啵啵王、礦坑 B2 的遠古巨像第一次進遊戲就在；頭上【MVP】、小地圖閃爍標記；會召喚手下、放紅色預警圈的範圍重擊。
- [ ] 擊敗 MVP：全服公告、MVP 獎勵進背包；世界地圖顯示重生倒數；時間到全服公告重生。

## 5. UI（階段 5）
- [ ] Alt+E 背包、Alt+Q 裝備、Alt+A 能力值、Alt+S 技能、Alt+U 任務、M 世界地圖、Esc 關閉最上層／開設定。
- [ ] 視窗可以拖曳、關閉，重新整理後位置保留。
- [ ] 背包雙擊使用藥水／穿脫裝備；道具資訊卡正確；拖到快捷列；拖到遊戲畫面丟在地上。
- [ ] F1~F9 使用快捷列道具／技能（聊天輸入中也可以）；數量與冷卻遮罩更新；右鍵清除。
- [ ] Enter 聊天、/help 指令；系統訊息分色。
- [ ] 道具商人、武器商人：購買（Zeny、負重檢查）、出售（半價）。

## 6. 任務（階段 6）
- [ ] 和 NPC 對話：打字機效果、點擊先顯示全文再翻頁、數字鍵選選項、Esc 關閉。
- [ ] NPC 頭上「!」可接任務、「?」可回報；接受後右側任務追蹤欄出現進度。
- [ ] 擊殺任務計數、收集任務依背包數量；完成回報得到經驗、Zeny、道具（收集品被收走）。
- [ ] 任務視窗可放棄任務；前置任務完成後才出現下一個。
- [ ] 旅館休息、設定儲存點；服務員傳送到去過的地圖。

## 7. 職業（階段 7）
- [ ] Job 10＋基本技能 Lv9 找轉職官 → 選劍士／法師／弓箭手 → 外觀與武器改變、全服公告。
- [ ] 劍士近戰；法師遠距魔力彈；弓箭手射箭（射程 9）。
- [ ] 技能：沒有目標時游標變成選目標模式；射程外會先走過去；詠唱條顯示在頭上；移動會中斷；冷卻遮罩；SP 不足提示。
- [ ] 12 個技能特效都正常（火焰彈、冰凍彈＋冰凍、靈魂衝擊、雷暴、重擊、爆裂斬＋擊退、挑釁、堅忍、二連矢、箭雨、集中、衝鋒箭）。

## 8. 成長（階段 8）
- [ ] 插卡：雙擊卡片 → 選有空插槽且未裝備的裝備 → 插入；能力值增加；資訊卡顯示卡片。
- [ ] 精煉師：安全值內必定成功；超過安全值有確認視窗，失敗裝備碎掉；+7 以上公告。
- [ ] Insert 坐下（基本技能 Lv3），回血加快；移動或被打會站起。
- [ ] 脫離戰鬥 5 秒後自動回血。
- [ ] 死亡：顯示扣除的經驗（初心者不扣）→「回到儲存點」。
- [ ] 存檔：關閉頁面再開啟進度還在；手動把 localStorage `rom.save` 改壞 → 自動用 `rom.save.bak` 還原。

## 9. 音效（階段 9）
- [ ] 點擊後開始播放 BGM；換地圖時音樂交叉淡入淡出（城鎮、草原、森林、海岸、沼澤、礦坑各不同）。
- [ ] 打擊、技能、升級、撿道具、UI 開關都有音效。
- [ ] 設定視窗三個音量滑桿立即生效，重新整理後保留。

## 10. 打磨（階段 10）
- [ ] `/fps` 顯示效能資訊：只繪製畫面附近的物件（物件數遠小於地圖總數）、粒子／飄字物件池重複使用。
- [ ] 全程 console 沒有錯誤。
- [ ] Lv1→10（含任務）約 20 分鐘；`tools/act/balance.js` 機器人只練功約 15 分鐘。
