# DECISIONS — 不確定時的決定（以「最像 RO」為原則）

| # | 主題 | 決定 | 理由 |
|---|------|------|------|
| 1 | 專案位置 | 放在 `yundu-game` repo 的 `ro-mmorpg/` 子資料夾，獨立的 Vite 專案 | 這次 session 只有兩個既有遊戲 repo 可寫；放子資料夾不影響《雲渡仙緣》的 GitHub Pages 與「無 build step」規則（那是 repo 根目錄遊戲的規則） |
| 2 | 原創內容 | 只仿 RO 的「玩法與手感」（等角視角、Q 版、點擊移動、六圍公式、轉職、卡片、精煉），**地名、怪物、NPC、技能名稱、美術全部原創**，不使用 RO 的名稱或圖 | 避免抄襲既有作品；遊戲名稱暫定《晨曦物語》 |
| 3 | UI 技術 | 遊戲世界畫在 canvas；視窗型 UI（背包、對話框…）用 DOM 疊在上面 | 中文字清晰、拖曳/捲動/輸入框容易做；canvas 仍維持像素清晰 |
| 4 | 等角格大小 | 菱形格 64×32 像素；角色 sprite 1:1 繪製（站高 128px ≈ 4 格高、1 格寬） | 與 RO 角色和格子的比例接近 |
| 5 | 縮放 | 整數倍縮放；邏輯畫面寬約 640~1400 遊戲像素，滑鼠滾輪 ±1 倍 | 規格要求只用整數倍；滾輪縮放是 RO 的操作 |
| 6 | 地形交界 | 逐像素生成地板，取樣地形前先做座標擾動（domain warp），交界變成自然曲線；較高層地形在交界投下 2~3px 陰影、水邊有白色浪花 | 比 16 種過渡貼片更自然，而且每種地形組合都自動有過渡 |
| 7 | 深度排序 | 以腳底 `x+y` 排序；多格建築依螢幕 x 切成 16px 直條，每條用前緣最高點的深度排序 | 單一深度值無法正確處理大型建築左右兩側的遮擋 |
| 8 | 角色間碰撞 | 角色與怪物之間不互相阻擋，可以重疊 | RO 就是這樣 |
| 9 | 移動手感 | 按住滑鼠會持續朝游標方向走；點地面會出現黃色菱形標記 | RO 操作 |
| 10 | 打擊停頓 | 玩家打中或被打中時，全域邏輯暫停 45ms（爆擊/技能 90ms），畫面震動 1.5~5px | 規格要求；只在與玩家有關的打擊才停頓，避免怪物互打時一直卡 |
| 11 | 血條位置 | 玩家與受傷怪物的血條畫在腳下 | RO 的樣式 |
| 12 | 能力值公式 | 採 RO 前期（pre-renewal）簡化版：素質ATK=STR+(STR/10)²+DEX/5+LUK/5（弓用 DEX 為主）、MATK=INT+(INT/7)²~INT+(INT/5)²、HIT=Lv+DEX、FLEE=Lv+AGI、命中率=80+HIT−FLEE（5~95%）、爆擊=1+LUK×0.3（無視迴避與防禦、×1.4）、完全迴避=1+LUK/10、防禦=裝備%減傷＋VIT 減法、ASPD=200−(200−職業武器基礎)×(1−(4AGI+DEX)/1000)，攻擊間隔=(200−ASPD)/50 秒 | 保留 RO 的加點取捨，公式集中在 `systems/Stats.ts`、`systems/Combat.ts` |
| 13 | 起始能力 | 六圍各 5、另有 24 點自由分配；加點花費 floor((x−1)/10)+2；每升一級得 floor(Lv/5)+3 點 | RO 建角總點數相近，但讓玩家一進遊戲就體驗加點 |
| 14 | 升級 | Base 升級補滿 HP/SP（RO 前期就是這樣）；Job 升級得 1 技能點 | |
| 15 | 經驗表 | Lv1→10 共需 609 Base 經驗；初心者 Job1→10 共需 365；轉職後另一張表，存在 `data/jobs.json` | 依「Lv1→10 約 20 分鐘」反推：每 8~10 秒一隻、平均 4~5 經驗＋任務獎勵 |
| 16 | 世界結構 | 晨曦鎮為中心：南→草原、東→森林；森林→海岸、礦坑；海岸→沼澤；礦坑 B1→B2 | 由易到難一條主線，RO 新手村周邊的感覺 |
| 17 | 小地圖方向 | 菱形（與等角畫面同方向），而不是 RO 的正北朝上 | 本作沒有旋轉鏡頭，菱形小地圖和畫面一致較直覺 |
| 18 | 地城照明 | 地城用黑暗遮罩＋火把光圈 | RO 地城較暗的氣氛；1/4 解析度讓光圈也是像素風 |
| 19 | 卡片掉率 | 一般怪 0.8%、MVP 5% | RO 原版 0.01% 對單機太低；仍保持「稀有」的感覺 |
| 20 | MVP 計時 | 用真實時間（Date.now）計算，存檔保存；玩家不在該地圖時也會倒數並公告 | 單機模擬「全服」：MVP 狀態與在不在線無關 |
| 21 | 追擊上限 | 主動怪在已有 3 隻追擊時不會加入；玩家主動打第 4 隻時，最遠的追擊者放棄並走回出生點 | 規格「同時追擊最多 3 隻」，又不讓玩家打了怪卻不反擊 |
| 22 | 撿道具 | 手動點擊撿取（RO 原味）；60 秒後消失 | |
| 23 | MVP 獎勵 | 掉落表第一項直接進背包＋額外 50% 經驗 | RO 的 MVP 獎勵機制 |
| 24 | 拖曳 | 自製 pointer 拖曳（不用 HTML5 DnD），滑鼠與觸控都可用 | HTML5 DnD 在觸控裝置不能用 |
| 25 | 丟棄道具 | 把背包裡的道具拖到遊戲畫面上就丟在腳邊（整疊） | RO 的操作方式 |
| 26 | 出售價格 | 原價一半 | RO 的商店規則 |
| 27 | 轉職條件 | 職業等級 10 且「基本技能」Lv9 | RO 初心者轉職規則；基本技能 Lv3 才能坐下 |
| 28 | 法師普攻 | 法師普通攻擊是遠距魔力彈（MATK×0.6、射程 6），不用 RO 的拿杖近戰 | 規格要求三種攻擊方式不同 |
| 29 | 箭矢 | 弓箭手不消耗箭矢 | 簡化背包管理；RO 需要箭 |
| 30 | 技能上限 | 一轉技能每個 Lv10，一轉職業等級上限 50 | RO 一轉 |
| 31 | 詠唱 | 詠唱時間 ×(1−DEX/150)；受到攻擊不會中斷，只有自己移動會中斷 | RO 公式；單機避免被小怪一直打斷 |
| 32 | 屬性 | 只做簡單的屬性加成（火對植物/蟲、水對蟹/石像、風對鳥/蝙蝠/蜂 ×1.25；靈魂衝擊對不死系加成） | RO 屬性表太大，保留「屬性有差」的感覺 |
