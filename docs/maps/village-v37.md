# 蘆花渡村整幅水彩場景（v37）

- 地圖世界仍為 42×28 格、每格 32px，手機直式與橫式共用同一張 3:2 斜視手繪村景。
- 場景主圖：`assets/img/village_map_v37.webp`，1344×896 WebP；原始生成圖與提示詞記錄在 `docs/art/village-v37/`。
- 村長廳位於北側中央；住家分布在上方與兩側；井在左側廣場、菜攤在右側、渡口與河面在南側。村民站位依地標分配：村長在廳前、阿婆在右側住宅、林嬸在井旁、老周在市集外緣、王大叔在渡口路口。主巷、橫向廣場、住宅、井、攤位、碼頭及河岸仍有資料碰撞與互動點。
- 人物仍由遊戲即時繪製和 y 軸排序；靜態場景物件以 `mapPlate` 標記不再重複繪製。河面以低透明動態水紋覆蓋；退水／漲水旗標仍影響岸線碰撞。
- 場景方向依據使用者提供的水彩村景參考，重新原創構圖；不包含角色、文字或 UI。

## 場景碰撞巡檢

- 碰撞以 `src/maps.js` 的 `buildVillage()` 資料矩形設定，背景圖本身不會自動阻擋玩家。屋舍主體、井、市集攤位、樹幹、院落圍籬、市集南側灌木／矮牆均設為障礙；樹冠可覆蓋道路視覺，但角色只被樹幹阻擋。
- 河面依水位動態阻擋，棧橋區域保持可走。院落及市集障礙保留入口和兩側繞行路線，村民、住家互動點與渡口皆須可達。
- `tests/village-layout.mjs` 抽查各類地標碰撞、路線可達及河岸水位；更新場景底圖時，需按新圖重新校正碰撞座標，避免只換圖、不更新站位或阻擋區。
