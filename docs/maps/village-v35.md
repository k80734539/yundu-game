# 蘆花渡村地圖重整（v35）

## 空間規劃

- 世界範圍：42×28 格，每格 32 世界像素（1344×896）；由斜視草地與獨立場景物件組成，鏡頭依玩家移動，不將整村縮進單一畫面。
- 北側是村長廳與住宅帶；西側巷道連回青舟舊居，東側住宅連阿婆家與小石頭；中央主路旁留出廣場、井和燈籠；東南魚市有攤位；南側小倉棚和院落接到河岸渡口。
- 主路南北貫穿村莊並直達棧橋；東西向支路串聯兩側住家、市集與廣場。短籬笆只圍院落邊，不封死支路。中央井移到主路側邊，渡口保持可直達。
- 村民分布在對應生活區：村長在北側廳前、阿婆在東側住家、林嬸在西側井巷、老周在南邊河岸、王大叔在棧橋附近。房間與床邊調查仍由互動點觸發。

## 河岸變化

水位由既有劇情旗標控制：一般狀態水線在 22.5 格附近；登船前退水後降至 21.2 格，露出濕泥岸；河伯事件後黎明升回 22.3 格。棧橋碰撞範圍隨水線保留安全通道。沒有新增存檔欄位或遷移。

## 素材來源

`art_source: existing`。沿用既有草地、泥路、房屋、井、攤位、籬笆、樹、燈籠和渡船素材，調整場景座標與地面路徑。沒有新增或生成美術圖片，因此不需改遊戲 CREDITS。
