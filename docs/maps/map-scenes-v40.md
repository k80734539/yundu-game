# 地圖全景底圖 v40

蘆葦蕩與河神廟依蘆花渡新地圖的水彩與淡墨風格製作。底圖採 960×720（20×15 格，每格 48 世界像素），與探索地圖範圍一致，不拉伸、不裁切。原始生成圖及提示詞存於 `docs/art/map-scenes-v40/`；素材來源是 Codex 內建 `image_gen`（host_image）。

蘆葦蕩由左上入口接入，石碑位於左側上半部，符紙與沉船在中段，營火在右下中景，牌坊出口在右下岸上；南側仍是水域。河神廟採中央院落，廟殿位於北側，河伯在殿前，石碑在左側中段，神龕與還願牌在中央偏下，石泉位於右側。

程式中的 GRID、路線、碰撞格、互動觸發、NPC 與任務狀態仍為遊戲資料來源。底圖已繪入固定植被、建築、石碑、神龕和泉池，避免再次疊畫；移動角色、寶箱、符紙、NPC、燈光和螢火蟲仍由遊戲即時繪製。河神廟入口、石碑與石泉的碰撞／互動位置已配合新構圖更新。地面水紋以低透明度輕疊，保留底圖原有水彩細節。

蘆花渡既有 42×28 全景不變。三張戰鬥背景仍採 `bg_*_v26.webp` 的 1672×941 橫向戰鬥構圖；已符合夜色水彩方向，因此不重新裁切或換成探索全景。
