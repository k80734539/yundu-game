## 音效接點

竹篙攻擊 → 青舟出手；實木打擊 → 青舟／白苓一般命中；靈力聚集 → 狐火／巨浪蓄力；狐火爆散 → 狐火命中；水彈命中 → 水擊／龍尾；蘆葦飛葉 → 飛葉命中；河伯巨浪 → 巨浪命中；春霖治療 → 春霖回復；使用道具 → 道具回復；會心一擊 → 會心命中；妖物消散 → 首次開始消散；角色升級 → 首次顯示升級訊息。

移動選項音用於選單移動，升調作確認聲；取消音用於取消、返回及關閉選單。地圖自由移動不播放選項聲。未提供的劍擊／防禦等仍使用既有合成回退；錄音未就緒也即時回退，不延遲傷害或操作。

## 處理與播放

- BGM 轉成 44.1kHz 立體聲 MP3，128kbps。去除首尾長留白，2 秒尾首交叉淡化，交給 Web Audio AudioBufferSourceNode 循環。
- 環境音為 22.05kHz 單聲道、64kbps，0.3 秒尾首交叉淡化。
- 音效為 44.1kHz 單聲道、96kbps；裁切留白與過長尾音，短淡入淡出防止切點爆音。依 RMS 與峰值平衡音量；所有輸出解碼峰值小於 1。實際數據見 manifest。
- 首次可信觸碰／按鍵後建立並恢復 AudioContext，才下載音訊。音效小檔預載；音樂隨場景下載，解碼快取最多兩首。快速切換以 ticket 排除過時解碼，不讓舊曲搶回播放。
- 切到背景時暫停 AudioContext 並停止短音效；音樂迴圈保留位置，下一次操作後恢復，避免疊播。
- 右上「聲音設定」含音樂、音效獨立開關，≥44px 觸控範圍，支援鍵盤及 aria 狀態，並各自保存。不更動存檔格式。上方目標文字預留按鈕空間。
