# 河伯戰：讓新玩家看得懂（文字草案 1）

> 狀態：**文字草案，尚未實作，請作者確認口吻與用詞。**
> 問題：第一次玩的人看不懂預告面板在做什麼（用字太像內部術語；只說「是什麼」不說「該怎麼辦」；沒有教學）。

## 原則
1. 用角色講重點（白苓、青舟的台詞），不用說明書。
2. 預告用白話，並標出危險程度（顏色：白＝普通、黃＝注意、紅＝大招、藍紫＝好機會）。
3. 擋浪只在第一次教，之後不再出現教學。
4. 面板只寫「現在對你有什麼影響」一句話，不寫抽象名詞。

## 預告用語（取代「預告 龍尾（平潮）」）
| 河伯的動作 | 顯示（一行） | 顏色 |
|---|---|---|
| 龍尾 | 龍尾橫掃：打一個人 | 白 |
| 蓄力 | 蓄力中：下一擊是濁浪！ | 黃 |
| 濁浪 | 濁浪滔天：全隊大傷！可撐篙擋住 | 紅 |
| 失衡 | 失衡：這回合動不了（趁機猛攻） | 藍紫 |
| 吞水（之後） | 吞水：河伯回復體力 | 黃 |
| 漩渦（之後） | 漩渦：封住一個人的技能 | 黃 |

顯示兩行：「下一步」「再下一步」（取代「預告」「再來」）。

## 潮位用語（取代「潮位 平潮」）
| 潮位 | 一句話 |
|---|---|
| 退潮 | 退潮：物理攻擊更強，河伯變弱 |
| 平潮 | 平潮：沒有變化 |
| 漲潮 | 漲潮：狐火更強，但河伯更凶 |

回合末的訊息：「潮水退去，河床露了出來。」「潮水漲起來了。」「潮水回到了平靜。」

## 渡氣用語
- 面板：「渡氣 35／100」，滿時改成「渡氣已滿：法術裡選『雲渡一擊』」。
- 取得時的小字：「擋得漂亮！渡氣 +35」。

## 角色台詞（戰鬥訊息框，格式「名字：「…」」）
開場（接在「頭目戰！河伯」後面）：
- 白苓：「他額頭的符在牽著他……小心他蓄力，那是濁浪的前兆！」
- 青舟：「看準浪頭，我用竹篙擋。」

第一次蓄力（只出現一次）：
- 白苓：「他在聚水了！下一擊是濁浪，全隊都會被打到！」
- 青舟：「交給我，看準光環！」

結果：
- 完美擋下：青舟：「接住了！」（反彈：「浪頭被我推回去了。」）
- 普通擋下：青舟：「擋住一半……」
- 沒擋到：白苓：「小心！快補血！」
- 失衡：白苓：「符裂了！他動不了了，快打！」
- 第一次引潮：白苓：「我來引一引潮水。」
- 渡氣滿：青舟：「渡氣滿了，白苓，一起上！」
- 合擊：（訊息）「青舟與白苓合力使出『雲渡一擊』！」
- 階段二：「額頭的符亮起紫光，河伯失控了！」

## 第一次擋浪教學（只教一次，用 `G.flags.parrySeen` 記錄）
光環出現時畫面略暗，上方文字：「看準光環縮到白圈的瞬間，點一下畫面！」
之後不再顯示這一行，改回「撐篙擋浪！」。

## 面板排版（之後做，先不動）
- 預告：河伯頭上兩個圖示氣泡（圖示＋短文字），大招紅框。
- 潮位：畫面左緣細長水位條，一個標記；點擊顯示一句話。
- 渡氣：小條放在指令鈕下方或角色卡旁，滿了發亮。
- 渡氣條不使用 ▮▯ 之類的符號字元（部分手機字型沒有，會顯示成「口」），一律用畫的。
