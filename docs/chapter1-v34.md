# 第一章〈夜渡〉劇情擴寫（v34）

## 新增主線段落

1. **登船前：退水現場**。完成村長與阿婆的委託後，第一次嘗試登船會看見河床退水、井水轉苦與村民送水。青舟向村長承諾會把船撐回來，為夜航建立更明確的代價。只播放一次；原存檔旗標自動保存。
2. **蘆葦蕩：竹篙與狐火**。取得控妖符並加入白苓後，在倒伏蘆葦前互動三次：先察看妖根，再用竹篙撐開、由白苓以狐火清理。場景表現兩人互相配合，完成後才可使用營火並離開蘆葦蕩。地圖目標提示說明下一步。
3. **河神廟：查碑與削弱封印**。必須先讀廟碑，接著在神龕前由青舟與白苓削弱控妖符對鎮水紋的牽引，之後才能與河伯交談並開戰。還願牌仍是可選探索內容。

## 保留的故事主軸

青舟救白苓、營火揭露墨刑、父親陳溯伏筆、河伯吐出河珠救小石頭、雲纖留下九霄宗與第二章懸念，順序和結局不變。新增旗標存放於既有 `G.flags`，無存檔格式遷移。
