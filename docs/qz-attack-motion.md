# 陳青舟普通攻擊原型

只處理青舟普通攻擊；白苓、技能、傷害公式、回合與操作均沿用既有程式。使用現有角色方向／步行圖及 Canvas 竹篙，沒有新增 AI 圖片。

| 毫秒 | 階段 |
| --- | --- |
| 0–90 | 蓄勢 |
| 90–230 | 衝向本次指定敵人近側 |
| 230–390 | 揮篙；340 ms 命中 |
| 390–450 | 收招 |
| 450–650 | 退回隊伍原站位 |

`src/battle_motion.js` 的 `QZ_ATTACK` 集中動作時間，`qzAttackPose()` 負責顯示座標，`drawQzAttack()` 負責姿勢；將來可在姿勢繪製處換成 AI 關鍵姿勢圖，保留移動／命中計時。

目標是本次 `exec(t)` 已選定的敵人物件，與之後的選單索引無關。站位使用 `battle_ui.js` 的同一套敵我幾何資料，每幀依當前直橫向與 safe area 重新計算。動畫角色限制在戰鬥舞台，裁除敵人名字及 HP 區域，不更改原有面板或點擊區。650 ms 結束直接恢復既有站位繪製，不累加座標偏差。

只有帶 `motion: qzAttack` 的特效事件增加 230 ms 延遲。原本 `VIMP.slash=110` 保留，因此刀光爆發、數字、受擊閃動與擊倒消散起點同為 340 ms；其他特效不加延遲。

HP 和回合維持原本結算方式，演出不再次扣血。玩家快速略過訊息時，依舊立即前進；未播放的命中視覺會快轉到命中點、角色立即復位，不新增輸入鎖定。更換戰鬥時舊動畫隨原戰鬥狀態清除。

測試：`npm run test:motion`（亦納入 `npm test`）。涵蓋五尺寸、三個選定敵人、340／650 ms 邊界、擊倒、首次繪製前略過、中途旋轉與其他技能時間。非會心測試另以像素確認底部面板未被動作覆蓋；會心閃白仍沿用原特效。
