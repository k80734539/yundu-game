# 探索介面與旅途手札（設計 v45，整合發佈 v47）

第一批 UI 實作範圍為探索 HUD 與主選單。沿用現有水彩地圖與 v28 使用者頭像（`art_source: existing`），沒有產生或替換美術；對話與戰鬥版面留待下一輪。發佈時已整合最新 v46，保留村莊／河神廟可走遮罩與河神廟左右支路修正；較早的矩形碰撞預覽已保存於本機 codex/ui-v45-snapshot 分支，不覆蓋線上碰撞。

## 樣式與配置

- 深靛底 `#10202d`、米白字 `#ede7d6`、少量細金框 `#b5a073`；青綠 `#95beb7` 表示目標與可互動，暖紅／淡藍表示氣血／靈力。
- 地名牌收在左上，任務用一個可點擊的短句顯示；橫式時併排，直式時上下排列，右上只留「選單」。探索聲音選項收進選單設定，標題與戰鬥仍保留原聲音按鈕。
- 旅途手札顯示隊伍現有頭像、等級、氣血、靈力；五個入口為隊伍、行囊、任務、存讀檔、設定，另有返回旅途。直式兩欄入口，矮橫式三欄；面板高度限制在安全區內，內容超高可捲動。
- 搖桿降低透明度；A 鈕旁顯示互動／交談／調查／登船／繼續，可互動時轉青綠。觸控操作位置維持原來習慣。

## 實際功能

`src/exploration_ui.js` 與 `src/exploration_ui.css` 管理本輪 UI。`journeyGoal()`、`journeyHint()` 使用現有旗標顯示目前階段，不新增存檔欄位。行囊是現有道具數量與用途資訊頁，使用道具仍走原戰鬥流程；本輪沒有新增地圖上使用道具的機制。

面板沿用 `SV` 存讀檔系統；開啟時清除按鍵／搖桿，`update` 在面板開啟時暫停移動。方向鍵、Enter、Esc、M 和 Tab 皆可操作；焦點限制在面板內。關閉後恢復探索。音樂／音效沿用原先獨立的 localStorage 設定、手勢解鎖及聲音素材。
