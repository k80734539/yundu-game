# 《雲渡仙緣》美術規範（Art Style Guide）

> 適用範圍：**所有新增或重畫的美術**（地圖、建築、角色、立繪、戰鬥姿勢、武器、特效、UI 插圖）。
> 現有素材與本規範的落差見 [`audit.md`](audit.md)。新素材不得再擴大落差；重畫時以本文件為準。
> 本文件只定義美術規則，不影響遊戲邏輯。

## 1. 整體風格

- **手繪水彩質感＋淡墨線**。不要純像素風（硬邊階梯鋸齒、低解析度色塊），也不要 3D／塑膠質感的渲染。
- 目標是《仙劍奇俠傳 1》那種「**每個場景都是一幅畫**」的感覺：構圖完整、有前中遠景、有氣氛（霧、月光、火光），而不是拼貼的素材堆。
- **視角**：全遊戲統一用**斜視（oblique／約 3/4 俯視）**，地圖、建築、物件、角色都用**同一個角度**。
  - 建築與物件要看得到屋頂或頂面的透視，地面為斜向向下展開；不要有的物件是正面立面圖、有的是接近正俯視。
  - 角色以 3/4 斜視為準；側身、背面姿勢的視角高度要與地圖一致。
- 邊緣：允許柔和暈染與少量紙紋／顆粒；不要出現「像素階梯＋抖色（dither）」當成主要質感。放大到 2 倍仍不能看到方塊像素。

## 2. 色彩

- **第一章〈夜渡〉基調**：夜藍（深藍、藍黑）＋灰青（霧、水、石）為底，**暖黃**只用在重點光源：營火、燈籠、神廟燭火。
- 暖黃要「少而準」：一個畫面裡暖黃面積應明顯小於冷色，才能顯出光源。
- **每章一組主色盤，最多 5～6 色**。新增美術從該章色盤取色（明度可變，色相不可亂跑）。新章開始時先在本文件追加該章色盤（色票＋HEX）再開工。
- 第一章主色盤（建議起點，實際取色請以現有背景 `bg_river.jpg` / `night.jpg` 為準，必要時調整並更新此處）：

  | 角色 | 用途 | 參考色 |
  | --- | --- | --- |
  | 夜藍 | 天空、遠山、水面暗部 | `#0f1d36` ～ `#1c3a5c` |
  | 灰青 | 霧、水面亮部、石頭 | `#4b6f78` ～ `#7a9aa0` |
  | 墨綠灰 | 蘆葦、苔、暗部地面 | `#2c3b32` |
  | 暖黃 | 營火、燈籠、燭火（重點光） | `#f2b84a` ～ `#ffd98a` |
  | 朱紅 | 廟柱、燈籠本體（小面積） | `#8e2f26` |
  | 骨白 | 白苓、霧中高光 | `#e8e4da` |

- **法術／特效色固定語意**：
  - **墨刑**：暗紫黑（`#2a1538` 附近，邊緣可帶一點紫亮）。
  - **河珠／水**：青白（青綠偏白，`#bfeff0` 附近）。
  - **狐火**：橘紅（`#ff7a2e` ～ `#ff4a1c`）。
- 白天／溫暖色系的素材（亮綠草地、亮橘磚等）進夜景前要先調到本章色盤，不要依賴全畫面疊一層半透明藍當作補救。

## 3. 線條與光影

- **角色輪廓線**：深色、細，**不是純黑**（用深藍黑／深褐，如 `#1a1424`），整套角色粗細一致。同一角色的地圖 sprite、戰鬥姿勢、立繪線條風格要一致。
- 物件（建築、道具）用同色系的較淡線條或乾脆以色塊交界表現，不要比角色線條更重。
- **主光源在左上，陰影落在右下**。每個角色、建築、物件都遵守。
- **點光源另外處理**：營火、燈籠、神廟燭火的暖光是局部光暈，加在主光之上，不要因為它們改變整張圖的主光方向。
- 夜景整體偏暗，但角色與可互動物件的輪廓要在手機亮度下讀得出來。

## 4. 比例與角色一致性

- **立繪**：約 **6.5～7 頭身**。**半身胸像**裁切在**下巴下方再帶一點肩膀**（要看得到下巴與雙肩，不可只裁到臉，也不可裁到腰）。
- 地圖 sprite、戰鬥姿勢圖、立繪三者**服裝細節必須一致**：
  - **陳青舟**：頭帶（暗紅，尾巴飄在腦後）、藍色交領短衫、灰長褲、黑靴、腰間布帶／竹篙握持。
  - **白苓**：白色狐耳（耳內粉）、白色長髮、白色交領長衣＋粉紅腰帶、**狐尾**（任何看得到背後的姿勢都要有尾巴）。
  - **雲纖**：黑色長髮、銀白髮冠、白底淺藍衣、藍色髮帶、佩劍。
  - 新角色先定「服裝細節清單」（髮型、頭飾、顏色、配件）寫進本文件，再三種圖一起畫。
- 同一場景中，成人角色的頭身比要在同一範圍；Q 版（約 2～3 頭身）只有在刻意設計成特殊角色時使用，並記錄在 `docs/art/`。

## 5. 武器與特效

- **武器一律手繪成圖片素材**（不用程式畫的線條代替）。目前的竹篙 `assets/img/qz_pole.webp` 是**手繪武器的參照基準**：有竹節、質感、握把細節、透明背景、握點已註冊。
- 特效顏色與角色／武器綁定：
  - **陳青舟**：金白（竹篙揮擊的拖尾與命中火花）。
  - **白苓**：青白（河水系，如春霖）或橘紅（狐火）。
  - **不要用通用藍色弧線**當萬用攻擊特效。
- 特效可以由 canvas 程式產生粒子與光暈，但**色彩、形狀語言要符合本章色盤與上面的綁定**；粒子總數維持在 `fx.js` 的上限（`VMAX=160`）內。

## 6. 檔案與驗收流程

- **每張新圖片都要在 `docs/art/` 留下文件**（可併入該功能的 md，如 `qz-attack-v17.md`），至少包含：
  - 檔名與路徑
  - 用途（地圖／立繪／戰鬥／特效）
  - 尺寸、是否 RGBA、基線／握點／錨點
  - **風格依據**（參考了哪些現有素材、遵守本文件哪些條目；若偏離須說明原因）
  - 提示詞／製作方式與來源（用於 `CREDITS.txt`）
- 同時更新 `CREDITS.txt`。
- **在真實手機直式大小驗收**，不只看大張原圖：
  - 用 390×664（以及 844×390 橫式）實際跑遊戲截圖，確認角色辨識度、輪廓、霧氣中的可讀性。
  - 立繪在對話框裡只有約 80～95 CSS px 見方（字級 × 5.2，390×664 實測）；頭身、五官、服裝要在這個尺寸仍然成立。
  - 地圖 sprite 在 390×664 畫面上目測約 45～55 CSS px 高；不可只靠 4 倍放大才看得出細節。
- 動畫幀（走路、攻擊）要逐幀檢查：輪廓不能破裂、衣襬不能缺塊、腳底基線不能跳。
- 完成後跟 [`audit.md`](audit.md) 對照，更新該表對應列的狀態。

## v28 頭像呈現補充

使用者提供角色四視角圖作為頭像來源；採三分之四正面、保留頭頂／狐耳／髮冠、下巴與雙肩，去背後裁至上胸。戰鬥底部採透明人像露出資訊列，參考使用者第四張的版面構圖，臉部不能被 HP/MP 或陰影遮住。對話使用相同原色圖並取消主角頭像的方框，NPC 頭像維持既有樣式。不要把提供的參考遊戲人物或素材複製進本作。

## 新地圖場景基準（依蘆花渡全景參考）

新地圖以使用者提供的蘆花渡全景圖為構圖與質感基準：完整可讀的一幅手繪水彩場景，細緻淡墨輪廓、柔和紙本色層、自然植被與石木建築；地面採斜視／3/4 俯視，讓人物能自然站在路面、庭院、碼頭等前景地面上。白天場景可用暖土色、灰瓦、草木綠與河水青綠；夜景依章節色盤轉換光線與色彩，仍保留水彩筆觸與清楚的地形層次。

- **遊戲地圖標準畫布**：蘆花渡基準為 42×28 世界格、每格 32 世界像素，底圖輸出 1344×896（3:2）。使用者參考圖本身為 1280×720（16:9），其完整全景感與視覺風格作為準則；轉成遊戲底圖時需重新安排構圖以符合目標地圖世界比例，禁止直接拉伸或硬裁掉重要地標。只有在玩法與世界資料明確改用其他尺寸時，才調整畫布比例，並同步更新地圖資料與碰撞。
- **全景構圖**：同一畫面交代主要地標、互相連接的道路／空地、住宅或場景邊界、前景地形（如河岸）。道路要有足夠寬度供玩家與 NPC 會車；重要入口、互動點及轉場方向要留出清楚空間。不要做成只有中央一條空路、兩側空白或無尺度的物件拼貼。
- **層次與活動空間**：遠景用樹林、屋舍與地形建立聚落輪廓；中景放主要建築、市集、井、橋等地標；前景可放河面、植栽、石岸與碼頭。人物實際行走的路面須保持平整、可辨識，植栽、牆、房屋、攤位、井與岸邊障礙需在碰撞資料中對應，不能只畫上去而可直接穿越；碰撞應留出繞行路徑和必要入口。
- **美術與遊戲分層**：背景圖只畫場景，不放人物、文字、任務標記、按鈕或 UI。玩家、NPC、可動物件與特效由遊戲分層繪製並依腳底座標排序；背景中的固定物件不重複疊畫。若樹冠／屋簷需要角色前後遮擋，將其做成獨立前景層或在遊戲內明確管理遮擋。
- **出圖提示詞必要條件**：指定完整遊戲場景、斜視／3/4 俯視、手繪水彩與淡墨、符合本章色盤、完整可行走地面、清楚地標及通道；明確排除人物、字樣、UI、格線、拼貼邊框、透視方向混雜與像素化。按實際場景調整季節、天候及光源，不要每張圖都複製村莊的建築配置。
- **驗收**：原尺寸確認構圖沒有拉伸、切掉入口或地標；在 390×664 直式與 844×390 橫式預覽確認關鍵地標仍可辨識、玩家不會被 UI 遮住；以碰撞網格或可達性測試檢查道路、NPC、互動點和出口，並實際走一次主要路線。

蘆花渡完整底圖 `assets/img/village_map_v37.webp` 是本基準的遊戲內示範；場景尺寸、地標及碰撞記錄見 [`docs/maps/village-v37.md`](../maps/village-v37.md)。
