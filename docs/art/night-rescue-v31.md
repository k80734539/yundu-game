# v31 夜渡站位與救人修正

使用者回報：主角像站在近側船舷，救人時白苓像橫放的站立人形，竹篙沒有連到手和衣帶。

沿用既有 night.jpg、青舟右向地圖 sprite 與白苓 bld_down 圖，未生成新素材。

- 船艙腳底移至原圖 (515,386)，救人時靠向 (535,386)，拉回後回到 (510,378)。青舟額外顯示倍率 1.45，修正成人和船／燈籠的比例。
- 近側船舷以原圖多邊形重繪於人物之前，避免鞋子與衣服疊在船身外。
- 白苓沿用蜷坐圖，水中露出上半身，水線以下裁切；由 (680,437) 經弧線拉到 (570,386)，過程 2200ms，逐漸回正並留在船艙。取消站立圖旋轉 90 度的舊作法。
- 竹篙有竹節、明暗與末端小勾；握點跟隨青舟的傾身，末端跟隨白苓衣帶，取消固定兩點直線。
- 移除人物獨立於船的上下浮動，只讓水中人物微幅隨波起伏。
- 對話與夜渡共用 dialogLayout；夜渡鏡頭根據文字框位置構圖，直式保留上方場景與下方對話／操作區。桌機保留底部對話，手機橫式保留上方對話。
- 劇本、碰撞、隊伍、存檔、戰鬥與輸入流程不變，連點仍可直接進入水妖戰。

驗證：night-rescue 六尺寸逐階段檢查船艙錨點、演出區、竹篙連接、水線與船上終點；polish 檢查原劇情與快速跳過；完整 npm test。

修正前：tests/baseline-v30/polish；修正後：tests/out/night-rescue 與 tests/out/polish。

夜渡以全段對話的最大高度預留空間，避免每換一句話，船就上下跳動或改變大小；旋轉視窗時重新計算。

驗收結果：npm test 全部 ALL PASS。最終固定鏡頭版本另跑六尺寸 night-rescue 全部 PASS，並親自檢視桌機與手機的站位、漂浮、拉人及船內蜷坐截圖。
