# v19 青舟／白苓／雲纖地圖行走 sprite

來源：內建 OpenAI `image_gen`（GPT 生成的行走圖），身份與服裝參考本專案立繪（`pt_qz.jpg`、白苓／雲纖立繪）與各自舊 sprite。白苓保留狐尾（四向可見）、雲纖腰間佩劍。不含第三方素材包。原始處理檔：`/workspace/yundu/art/{qz,bl,yx}/out/`（未入庫），預覽各目錄 `sheet_check.png`。三人以同一標準處理：最高一幀＝170 px，所以可共用同一個顯示縮放。

## 素材
| 素材 | 規格與用途 |
| --- | --- |
| `assets/img/{qz,bl,yx}_{down,up,left,right}{0,1,2,3}.webp` | 每人 16 張（共 48），192×192 RGBA 真透明，webp quality 85。地圖行走、隊伍跟隨、演出、戰鬥隊列、標題畫面使用 |

- 幀定義：**0 左腳前、1 站立、2 右腳前、3 站立**。走路循環 0→1→2→3，站立（idle）＝第 1 幀。左向是右向的鏡像。
- 錨點：腳底邊緣在 y=180（最低不透明列 179），人物水平置中 x=96，身高約 165–170 px。
- 三人的舊 sprite（72×66、3 幀、可見身高約 60 px、腳底 y=66）已被取代並只留在 git 歷史；**王大叔與其他 NPC 仍使用舊規格**，引擎同時支援兩種格式。

## 引擎規格（`src/ui.js` 的 `SPR`）
- `SPR = {qz, bl, yx}` 共用 `{n:4, idle:1, seq:[0,1,2,3], map:[1,0,2], k:.353, fh:180}`；不在 `SPR` 的角色走舊預設（n=3、k=1、腳底＝圖高）
- 顯示縮放 `k=0.353`：可見身高 ≈ 60 px，與舊 sprite 等高；寬度 192×k≈68 px。
- `sprDraw(key,x,y,s)`：以地面腳底點 (x,y) 為準，圖頂 = `y+2-fh*k*s`（舊 sprite 同式 `fh=66,k=1`，結果與舊版逐像素相同）。陰影仍以 (x,y-1) 為中心。
- `spriteKey(k,dir,f)`：有 `SPR` 的角色用 `seq`／`idle`，其餘仍為舊 `[0,1,0,2]`、站立 0；缺圖 fallback 同舊邏輯。舊影格名（`qz_down0` 等）仍存在，只是語意變成「左腳前」。
- 戰鬥隊列：`SPR.map` 把舊影格 0（站）/1（衝刺）/2（踏步）對應到新影格 1/0/2；繪製以腳底對齊舊 sprite 的站位。`qzAttackPose`（只有青舟有攻擊姿勢）的尺度基準固定為舊 72×66（`72*ps,66*ps`），所以 v17 攻擊動作的大小、握點完全不變。
- 標題畫面、夜渡演出、`screens.js` 角色展示一律走 `sprIdle()`＋`sprDraw()`。

## 注意
- 新圖為高解析、帶渲染質感的繪畫風；舊 sprite 是低解析像素風。縮到地圖尺寸後並排仍可接受，但風格有落差（三位主角較細緻、輪廓較銳利）。王大叔與 NPC 仍是舊像素風，長期應以同一風格重做。
- 影格順序不可再改成其他排列；新增 4 幀角色時在 `SPR` 加一筆即可。
