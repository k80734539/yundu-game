# v30 戰鬥手感與音效

保留 v29 站位、原圖、戰鬥數值和命中時間。既有攻擊前踏步及回位動作保留。

- 普通命中暫停攻擊者繪圖時鐘 55ms，會心／重擊 80ms；定格後接續動作，回位延後同等時間，訊息、傷害和操作不暫停。
- 敵我受擊沿遠離攻擊來源方向後退，普通 7、會心 11、防禦 4、河伯 3 縮放像素；前 55ms 保持，260ms 內回到原位。治療／零傷害不後退，停止敵人受擊時的待機浮動。
- 原創 Web Audio 音效：揮擊風聲、水擊、狐火、治療、護盾、中毒。音量總線 22%，同時最多 16 個音源；無背景音樂。
- 音效開始跟隨出手延遲，命中聲與 VIMP 同步，每個動作只播放一次，連點不重複。
- 首次可信點擊／觸碰／鍵盤操作解鎖，支援 webkitAudioContext；不支援時無聲運行。切到背景停止音源並暫停音訊，回到遊戲後由操作恢復。
- 右上音效開關 ≥44px、支援鍵盤和 aria-pressed，設定獨立儲存於 yundu_sound；戰鬥訊息框預留右緣，不遮擋文字；對話、演出及存檔面板期間隱藏開關，標題版本標籤向左讓位。

驗證：tests/battle-feedback.mjs 測量真實 AudioContext 取樣非零、開關音量、重新整理靜音、缺少 API 回退、一次出手與命中聲、定格／受擊方向／回位／治療不後退及 HP 不變。既有 diag-battle 驗證動作序列、衝刺避碰與跳過。

基準：tests/baseline-v29/fx；新版截圖 tests/out/fx、tests/out/battle-feedback。

驗收結果：npm test 完整測試 ALL PASS。已另外驗證鍵盤切換音效、對話自動隱藏，以及命中暫停後繼續播放動作。已親自檢視橫直戰鬥、橫式對話與標題截圖。
