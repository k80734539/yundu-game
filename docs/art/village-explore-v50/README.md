# 村莊拾取物圖片（v50）

`src/village_explore.js` 的四個拾取物使用下列圖片，登記在 `src/assets.js`：

| 檔案 | 物品 | 用途 |
|---|---|---|
| `assets/img/vx_sinker.webp` | 網墜 | 老周委託「找回網墜」，在北邊小路 |
| `assets/img/vx_basket.webp` | 竹籃 | 王大叔委託「河邊的竹籃」，在渡口東邊岸上 |
| `assets/img/vx_fish.webp` | 魚乾 | 西側院落的隱藏獎勵 |
| `assets/img/vx_herb.webp` | 清心草 | 東側小屋南邊的隱藏獎勵 |

## 來源與處理

- 來源：Codex 內建 `image_gen` 原創生成，單一物件、斜視（3/4 俯視）、水彩手繪加淡墨線、光源左上，風格對齊 `village_map_v37.webp`。原始生成為 256×256 RGBA webp。
- 處理（Claude）：
  1. 檢查：四張皆為真透明 RGBA，畫布邊緣沒有不透明像素。
  2. 清除 alpha < 20 的極淡殘影（每張約 400 到 1200 個像素）。
  3. 裁到物件邊界並留 2 px 邊，輸出無損 webp。尺寸：網墜 98×135、竹籃 137×144、魚乾 184×211、清心草 187×205。
- 為什麼要裁：程式用整張圖的高度當顯示高度，原圖留白大小不一（網墜只佔畫布一半），不裁的話物件會比設定小、也會浮在地面上方。裁完後 `VX_PICKUP_ART` 的 `h` 就是畫面上物件的實際高度（世界像素）：網墜 20、竹籃 22、魚乾 22、清心草 24。

## 提示詞

生成的提示詞沒有隨檔案附上（圖片是以壓縮檔交付）。風格要求見 `docs/art/style-guide.md`，物件描述如下：

- 網墜：漁網用的鉛墜子，灰黑金屬，有穿繩孔。
- 竹籃：菜販的舊竹籃，籃底有補過的痕跡。
- 魚乾：一兩條用草繩串著的曬乾小魚。
- 清心草：一小束淡綠藥草，用細繩綁著。

## 顯示

有圖時畫物件圖，並在物件右上角畫一個小閃光提示；圖載入失敗時改畫大閃光（fallback）。撿起後消失，不重生。
