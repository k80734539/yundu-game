# v25 橫向斜排戰鬥站位

依使用者補充的橫式戰鬥參考，敵人在左、我方在右；兩隊皆從左下前排向右上後排延伸。保留原創角色、敵人美術與戰鬥數值，不新增圖片。

橫式以實際可用寬度分配兩側位置，腳底從底部卡片位置往上計算。直式也保留左右對陣方向，增加斜向深度，以便在較窄畫面保留三位隊友的辨識度。單敵、雙敵、三敵、河伯各有站位，敵人按腳底 y 由遠到近繪製，選取索引與行動順序不變。

延用六姿勢共用腳底與顯示倍率；陰影、生命列、點擊範圍、攻擊特效與衝刺終點都使用同一組站位。更新 UI 與圖片快取版本為 25。

驗收圖：tests/baseline-v24/enemy-layout/ 為修正前；tests/out/enemy-layout/ 為修正後，涵蓋 390×664、375×553、430×750、664×390、844×390，另加入參考圖比例的 1024×768，每尺寸包含 single、pair、trio、boss。tests/enemy-layout.mjs 檢查敵人位於隊伍左方、兩隊向右上排列及敵人不被裁切；既有 diag-battle 檢查不重疊、觸控區、衝刺與動作回歸。

小尺寸橫式的敵方整隊上移 30 設計像素，讓最前排敵人的名稱與血條位於人物頭像上方；enemy-layout 對此有獨立斷言。

4:3 橫式另依可用寬度保留敵方左緣空間，避免最前排被裁切。驗收：完整 npm test → ALL PASS；最後位置微調後另重新通過六尺寸站位與三尺寸動作檢查。20 組 v24／v25 截圖差異與比較數據位於 tests/out/enemy-layout/diffs/、comparison.json；已目視檢查 390×664、664×390、844×390、1024×768。
