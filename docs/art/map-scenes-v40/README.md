# v40 exploration map art

- Art source: Codex built-in `image_gen` (`host_image` route).
- Original generated masters: `reeds-map-original.png`, `temple-map-original.png` (1448×1086 RGB).
- Prompts: `reeds-map-prompt.txt`, `temple-map-prompt.txt`.
- Runtime derivatives: `assets/img/reeds_map_v40.webp`, `assets/img/temple_map_v40.webp` (960×720; 20×15 world cells at 48px/cell; 4:3; WebP quality 92).
- Both masters were composed to match their gameplay landmarks and entrances. The original GRID collision and quest data remains authoritative; static environment scenery is baked into the plates.
- Existing village map is unchanged. Existing three battle backgrounds remain in their screen-specific 1672×941 landscape format because they already use the chapter's watercolor night palette and valid combat floor framing.
